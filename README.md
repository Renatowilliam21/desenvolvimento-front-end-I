# Desenvolvimento Front-End I

Repositório destinado às atividades práticas desenvolvidas na disciplina de **Desenvolvimento Front-End I**.

## Atividades

### Atividade 01 — Aplicativo de Imóveis

Desenvolvimento de uma aplicação mobile utilizando React Native e Expo.

Principais recursos trabalhados:

- criação de componentes;
- estilização de interfaces;
- exibição de listas;
- navegação entre telas;
- passagem de parâmetros entre telas;
- cadastro e visualização de imóveis.

Diretório: [`atividade_01_v2`](./atividade_01_v2)
